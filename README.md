# LLMDSHPlugin

A collection of DSH (DeepSeek Harness) plugins. Each plugin is maintained in its own repository and released independently.

## Plugins

- [LLMDSHPlugin_token-usage](https://github.com/ai-v5/LLMDSHPlugin_token-usage): sidebar token usage statistics with an all-time total, a 365-day calendar heatmap, turn/step counts, average generation speed, and durable history across archived sessions.

## Install

```powershell
dsh plugin --profile desktop add github:ai-v5/LLMDSHPlugin_token-usage
```

This repository is the collection index. Plugin source, issues, tests, and releases live in each plugin's own repository:
